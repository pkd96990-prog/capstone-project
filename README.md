# capstone-project
Student Performance Prediction using Decision Tree and Random Forest models. This capstone project analyzes academic and demographic factors to predict student pass/fail outcomes and compares model performance using real-world educational data.
<h2>Student Performance Prediction</h2>

<p>
This capstone project focuses on predicting student academic performance using
machine learning techniques. The goal is to classify whether a student will pass
or fail based on academic and demographic factors.
</p>

<h3>Dataset</h3>
<p>
The Student Performance Dataset is used in this project. It includes information
related to students’ study habits, past academic performance, attendance,
and family background.
</p>

<h3>Approach</h3>
<p>
The dataset was explored and preprocessed before training the models.
Categorical data was converted into numerical form, and the final grade was
transformed into a pass/fail target variable.
</p>

<h3>Models Used</h3>
<ul>
    <li>Decision Tree Classifier</li>
    <li>Random Forest Classifier</li>
</ul>

<h3>Model Comparison</h3>
<p>
Both models were evaluated using standard classification metrics.
The Random Forest model achieved better accuracy and generalization
compared to the Decision Tree model.
</p>

<h3>Conclusion</h3>
<p>
This project demonstrates the use of machine learning in educational data
analysis to identify factors affecting student performance and predict outcomes.
</p>
